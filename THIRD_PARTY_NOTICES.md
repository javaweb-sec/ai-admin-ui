# 第三方许可

项目组合使用 React、Vite、Tailwind CSS、Radix UI、shadcn/ui、Lucide、Zustand、React Router、Recharts、UIW Markdown Editor 等开源项目。

- shadcn/ui 组件源文件基于 MIT 许可的组件模式，组件代码位于 `src/components/ui`。上游：https://github.com/shadcn-ui/ui
- Lucide 图标遵循 ISC 许可。上游：https://github.com/lucide-icons/lucide
- 其他 npm 依赖的版本以 package-lock.json 为准，许可文本位于安装后的对应包中。
